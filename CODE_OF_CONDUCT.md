# Code of Conduct

This project has adopted the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short:
- Be respectful and welcoming.
- Assume good intent.
- Give constructive feedback.
- Harassment of any kind isn't tolerated.

## Reporting

Report unacceptable behavior privately to the maintainer through a [GitHub security advisory](https://github.com/tamujin/pwsh-project-jump/security/advisories/new), or by contacting [@tamujin](https://github.com/tamujin) on GitHub. All reports are reviewed and handled confidentially.
